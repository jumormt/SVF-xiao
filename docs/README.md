# SVF-Teaching
Learning and Teaching Software Analysis, Verification and AI via [SVF](https://github.com/SVF-tools/SVF)

## SVF Harness Tutorial

The comprehensive `svf-harness` tutorial is an mdBook source tree at
[`harness-book/`](harness-book/). It covers the full query surface, Codex MCP,
and Codex skills usage. Build it with:

```bash
mdbook build docs/harness-book
```

On Ubuntu 20.04 focal, use the mdBook `x86_64-unknown-linux-musl` release binary
if the default GNU binary requires a newer glibc.

The older script-backed walkthroughs remain in [`tutorials/`](tutorials/).
